# VoiceDictationSTT

Windows-приложение для голосовой диктовки: записывает речь с микрофона, распознает ее через Faster-Whisper и позволяет редактировать, копировать и экспортировать результат в TXT или DOCX.

Приложение ориентировано на локальную работу. При первом использовании выбранной модели нужен интернет для скачивания файлов модели, после этого распознавание может работать офлайн.

## Возможности

- Запись речи с микрофона.
- Распознавание русского и английского языка, а также автоопределение языка.
- Режимы точности: быстрый, сбалансированный и максимальный.
- Автопунктуация средствами Whisper.
- Редактирование распознанного текста в окне приложения.
- Экспорт в TXT и DOCX.
- Копирование текста в буфер обмена.
- Автосохранение текста.
- Временные метки.
- История последних сохраненных файлов.
- Темная тема.
- Горячие клавиши: `Ctrl+R`, `Ctrl+P`, `Ctrl+S`, `Ctrl+C`.

## Модели распознавания

Размер модели зависит от выбранного режима:

- `Быстрый` - `tiny`.
- `Сбалансированный` - `small`.
- `Максимальная точность` - `medium`.

Модели сохраняются в `%APPDATA%\VoiceDictationSTT\models`.

## Установка для разработки

Требуется Windows 10/11 и Python 3.10 или 3.11.

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

Также можно запустить:

```bat
run_dev.bat
```

## Сборка EXE

```bat
build_exe.bat
```

Готовая сборка появится здесь:

```text
dist\VoiceDictationSTT\VoiceDictationSTT.exe
```

## Данные приложения

- Настройки: `%APPDATA%\VoiceDictationSTT\settings.json`.
- Автосохранение: `%APPDATA%\VoiceDictationSTT\autosave_transcript.txt`.
- Лог ошибок: `%APPDATA%\VoiceDictationSTT\app.log`.

# VoiceDictationSTT — Windows-приложение для голосовой диктовки

Бесплатное офлайн-ориентированное приложение для Windows 10/11: запись с микрофона, расшифровка речи в текст через Faster-Whisper, ручное редактирование, экспорт TXT/DOCX, автосохранение, логирование и горячие клавиши.

## Возможности

- Простое окно с кнопками: начать, пауза, остановить, очистить, копировать, экспорт TXT, экспорт DOCX.
- Индикаторы состояния: ожидание, запись, пауза, обработка, ошибка микрофона.
- Большое редактируемое поле расшифровки.
- Выбор микрофона.
- Языки: русский, английский, автоопределение.
- Режимы точности: быстрый, сбалансированный, максимальная точность.
- Автопунктуация средствами Whisper.
- Удаление слов-паразитов простым постпроцессингом.
- Нормализация громкости аудио перед распознаванием.
- Предупреждение при низком уровне сигнала микрофона.
- Автосохранение во временный файл.
- Экспорт TXT UTF-8 и DOCX со стандартным шрифтом Calibri 12.
- Счётчик слов и символов.
- Горячие клавиши: Ctrl+R, Ctrl+P, Ctrl+S, Ctrl+C.
- Тёмная тема.
- Временные метки.
- История последних сохранённых файлов.
- Лог ошибок в `%APPDATA%\VoiceDictationSTT\app.log`.

## Важное замечание о бесплатности

Решение использует бесплатные open-source библиотеки. Faster-Whisper при первом запуске скачивает модель распознавания. Это бесплатно, но требует интернет-соединения и свободного места на диске. После скачивания модель кэшируется и может использоваться офлайн.

Размеры моделей зависят от режима:

- `Быстрый` → `small`.
- `Сбалансированный` → `medium`.
- `Максимальная точность` → `large-v3`.

Для слабого компьютера режим максимальной точности может работать медленно. В `main.py` можно заменить `large-v3` на `medium` или `large-v2`.

## Установка для разработки

1. Установите Python 3.10 или 3.11 для Windows.
2. Распакуйте проект.
3. Запустите `run_dev.bat`.

Или вручную:

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

## Сборка EXE

Запустите:

```bat
build_exe.bat
```

Готовая программа будет в папке:

```text
dist\VoiceDictationSTT\VoiceDictationSTT.exe
```

По умолчанию PyInstaller создаёт папку с EXE и зависимостями. Это надёжнее для Faster-Whisper, чем один огромный EXE. Если нужен именно один файл, можно попробовать заменить команду PyInstaller на:

```bat
pyinstaller --noconfirm --clean --windowed --onefile --name VoiceDictationSTT --collect-all faster_whisper --collect-all ctranslate2 --collect-all PySide6 main.py
```

Однако режим `--onefile` может дольше запускаться и чаще требует донастройки для тяжёлых ML-библиотек.

## Архитектура

- `MainWindow` — интерфейс PySide6, настройки, экспорт, история, автосохранение.
- `RecorderWorker` — отдельный поток записи аудио с микрофона через `sounddevice`.
- `TranscriberWorker` — отдельный поток распознавания через `faster-whisper`.
- Аудио пишется чанками во временные WAV-файлы, затем обрабатывается моделью.
- UI не блокируется во время записи и распознавания.
- Настройки сохраняются в `%APPDATA%\VoiceDictationSTT\settings.json`.
- Автосохранение текста: `%APPDATA%\VoiceDictationSTT\autosave_transcript.txt`.
- Логи ошибок: `%APPDATA%\VoiceDictationSTT\app.log`.

## Ограничения текущей версии

- DOCX поддерживается полноценно; старый бинарный DOC не реализован, так как он устаревший и хуже поддерживается open-source библиотеками.
- Исправление орфографии оставлено как настройка интерфейса, но в этой базовой версии не подключён отдельный орфографический движок. Для русского языка можно добавить LanguageTool или локальный hunspell-пайплайн.
- Шумоподавление реализовано минимально: VAD в Faster-Whisper, нормализация громкости и предупреждение о тихом сигнале. Для более сильного шумоподавления можно добавить RNNoise/WebRTC NS.

## Обновление v3: окно загрузки модели

В программу добавлена проверка наличия модели Faster-Whisper перед стартом диктовки.

Если выбранная модель ещё не скачана, приложение:

1. показывает сообщение «Модель не скачана»;
2. открывает отдельное окно загрузки модели;
3. показывает активный индикатор процесса;
4. запрещает запуск диктовки до завершения загрузки;
5. после успешной загрузки сообщает, что можно начинать диктовку.

Также в настройках добавлена кнопка:

`Скачать / проверить модель`

Её можно нажать заранее, чтобы скачать модель до начала диктовки.

Для первого теста рекомендуется выбрать режим `Быстрый`, потому что он скачивает меньшую модель `small`.


## Обновление v4

В окно загрузки модели добавлен детальный прогресс:

- процент выполнения;
- сколько КБ уже скачано;
- общий размер модели в КБ;
- имя текущего скачиваемого файла.

Модели теперь сохраняются в локальную папку приложения `%APPDATA%\VoiceDictationSTT\models`, поэтому программа может точно проверять, скачана ли модель, без обращения к интернету.

## Обновление v5: исправление задержек и неправильных статусов

Изменена логика диктовки:

- запись с микрофона стартует только после полной загрузки модели в память;
- статус «Ожидание» больше не показывается, пока запись или обработка реально продолжается;
- при остановке программа сначала завершает запись, затем дорабатывает очередь аудио и только потом возвращается в «Ожидание»;
- режимы моделей стали легче для CPU:
  - `Быстрый` → `tiny`;
  - `Сбалансированный` → `small`;
  - `Максимальная точность` → `medium`;
- длительность аудиофрагментов уменьшена:
  - быстрый режим — 2 секунды;
  - сбалансированный — 4 секунды;
  - максимальная точность — 6 секунд;
- отключено `condition_on_previous_text`, чтобы модель не повторяла старый контекст и меньше «придумывала» текст;
- пустые и слишком тихие фрагменты не отправляются в распознавание;
- финальный фрагмент при нажатии «Остановить» теперь корректно отправляется в обработку.

Для минимальной задержки используйте режим `Быстрый`. Для более качественного текста — `Сбалансированный`.
